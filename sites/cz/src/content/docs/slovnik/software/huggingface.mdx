**Hugging Face** (často jen „HF“) je největší veřejné úložiště modelů
pro lokální AI. Když návod říká „stáhněte model“, většinou to znamená
„stáhněte ho z Hugging Face“. A když se objeví „HF token“, jde o
přístupový klíč, který je potřeba chránit jako heslo.

## Rychlá odpověď

- **Model = repozitář** s váhami, konfigurací, tokenizerem a model
  card. Vždy si přečtěte model card a licenci.
- **HF token** potřebujete pro gated modely, vyšší limity, privátní
  repozitáře nebo nástroje, které ho vyžadují. Pro běžné veřejné
  modely často stačí stahovat bez něj.
- **Token patří do proměnné prostředí**, ne do gitu, Markdownu ani
  screenshotu. Pro stahování stačí právo Read.

## Jak to funguje

Hugging Face funguje jako GitHub pro modely:

- **Repozitář** obsahuje váhy modelu, konfiguraci a tokenizer.
- **Model card** je popis: co model umí, jaká má omezení a licenci.
- **Velké soubory** jsou uložené přes Git LFS, takže se stahují po
  částech a dají se obnovit při přerušení.
- **Organizace** (např. `Qwen`, `unsloth`, `meta-llama`) vydávají
  modely pod svým jménem.

Pro vás je podstatné, že model je **jeden repozitář**, ne sbírka
souborů z různých míst. Odkaz na model card je zároveň zdroj, který
můžete ověřit.

## Jak najít správný model

Před stažením zkontrolujte pět věcí:

| Co | Proč |
|---|---|
| **Název a verze** | jiná verze může mít jiné chování i licenci |
| **Kvantizace** | NVFP4, FP8, GGUF Q4_K_M, MLX 4bit — liší se pamětí i kvalitou |
| **Velikost** | musí se vejít do 128 GB včetně KV cache |
| **Licence** | komerční použití, teritoriální omezení, povinnosti |
| **Engine** | vLLM, llama.cpp, MLX — ne každý model jede všude |

U Qwen3.8 Flash Next je kanonický zdroj
[model card Qwen/Qwen3.8-Flash-Next](https://huggingface.co/Qwen/Qwen3.8-Flash-Next).
Kvantizace od Unsloth nebo NVIDIA jsou odvozené repozitáře; vždy se
ptejte, z jakého základu vznikly.

## K čemu je token

Bez přihlášení se dá stáhnout většina veřejných modelů. Token
(`HF_TOKEN`) se hodí, když:

- model vyžaduje **souhlas s licencí** (gated model),
- chcete **vyšší limity** stahování,
- stahujete z **privátního** repozitáře,
- nástroj token vyžaduje kvůli jednotnému nastavení.

Token je vaše heslo pro strojový přístup. Nikdy ho nedávejte do
veřejného repozitáře ani do screenshotu.

## Jak token vytvořit

1. Přihlaste se na [huggingface.co](https://huggingface.co/).
2. Otevřete **Settings → Access tokens**.
3. Klikněte na **Create new token**.
4. Zvolte **Read** (pro stahování modelů stačí; zápis nepotřebujete).
5. Token zkopírujte — zobrazí se jen jednou.

Pro tým použijte organizační token s omezeným rozsahem a platností,
ne svůj osobní token.

## Kde token použít

V terminálu jako proměnnou prostředí:

```bash
export HF_TOKEN="hf_váš_token"
```

Nebo přihlášením v Python nástroji:

```bash
huggingface-cli login
```

V Dockeru se předává jako proměnná:

```bash
docker run -e HF_TOKEN=$HF_TOKEN ...
```

`llama.cpp` a `vLLM` token čtou z `HF_TOKEN`, takže ho nemusíte
vkládat do příkazů ručně.

## Bezpečnost

- Vytvořte token s právem **Read**, ne Write.
- Když unikne, **okamžitě ho zrušte** v nastavení a vytvořte nový.
- Nedávejte ho do Markdownu, do gitu ani do sdíleného skriptu.
- Pro tým použijte organizační token s omezeným rozsahem, ne osobní.
- Token v shellu může zůstat v historii; používejte `.env` nebo
  správce tajemství.

## Časté chyby

- **401 Unauthorized** — token chybí, je expirovaný nebo nemá správné
  oprávnění.
- **Gated model** — musíte nejdřív na model cardu odsouhlasit licenci.
- **Malý disk** — model má desítky GB a stažení se může přerušit.
- **Špatná kvantizace** — stáhnete jinou velikost, než návod předpokládá.
- **Token v gitu** — i smazaný commit může zůstat v historii.
