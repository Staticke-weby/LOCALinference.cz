**AI workspace** je aplikace, která zobrazuje práci agenta: chat,
diffy, terminál, session a historii. Není to model ani harness;
je to **kontrolní místo**, kde vidíte, co agent udělal, a
rozhodujete, co se stane dál.

## Rychlá odpověď

- **Workspace ≠ IDE.** Neupravuje kód, jen ukazuje změny.
- **Workspace ≠ harness.** Smyčku vede harness; workspace ji
  zobrazuje.
- **Přínos:** přehled, review, práce z víc zařízení.
- **Příklad:** OpenChamber nad OpenCode.

## Co workspace umí

- **Session** — historie konverzací a běhů.
- **Diff** — co se změnilo a kde.
- **Worktrees** — paralelní úlohy v izolaci.
- **Review** — schválení, komentáře, merge.
- **Vzdálený přístup** — web, mobil, relay.
- **Náklady** — tokeny a spotřeba.

## Jak se liší od IDE

| Co | AI workspace | IDE |
|---|---|---|
| Účel | řídit agenta | editovat kód |
| Výstup | diff a review | soubory a build |
| Práce agenta | vidíte a schvalujete | spouštíte v terminálu |
| IDE integrace | volitelná | základ |

Workspace se používá **vedle** editoru, ne místo něj.

## Kdy se vyplatí

- Když agent mění víc souborů a chcete vidět diff.
- Když běží víc agentů nebo modelů.
- Když pracujete z notebooku i z telefonu.
- Když potřebujete historii a audit.

## Kdy ne

- Když stačí terminál a jeden příkaz.
- Když agent jen odpovídá textem.
- Když nemáte čas na další vrstvu.
- Když jde o jednorázový skript.
