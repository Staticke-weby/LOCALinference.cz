**MTP** (multi-token prediction) je technika, kdy model nenavrhuje
jeden token, ale několik dopředu. Další výpočet je pak rychlejší,
protože se část práce dělá paralelně.

## Jak to funguje

Model při generování „hádá“ několik dalších tokenů. Návrhy se ověří
najednou — a když sedí, jsou hotové bez čekání. Když ne, zahodí se
a pokračuje se klasicky.

Je to stejný princip jako **spekulativní dekódování**: levná část
navrhne, drahá část potvrdí. Zrychlení závisí na tom, jak často návrhy
sedí.

## Kde se potká

- **[vLLM](/slovnik/software/vllm/)** — MTP je součástí doporučeného
  nasazení Qwen3.8 Flash Next na DGX Sparku.
- **[llama.cpp](/slovnik/software/llamacpp/)** — podporuje MTP u modelů,
  které ho mají.
- **Naměřená čísla** se proto rozcházejí: s MTP a bez něj může být
  rozdíl desítky procent.

## Co to znamená pro vás

- **Bez MTP** je bezpečné číslo pro plánování.
- **S MTP** je horní hranice, které lze dosáhnout při dobré shodě návrhů.
- Když se čísla v tabulce liší, hledejte právě tohle nastavení.

MTP nemění kvalitu odpovědi — jen způsob, jak se k ní model dostane.
Pokud se návrhy neshodují, výhoda mizí.
