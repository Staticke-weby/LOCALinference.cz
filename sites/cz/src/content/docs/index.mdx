## Lokální AI pro firmy: pro koho je web

Pro **majitele firem, CTO, podnikatele a vedoucí IT**, kteří zvažují
vlastní AI. Máte rozpočet na zařízení a chcete vědět, jestli se to
vyplatí, co to zvládne a kde narazíte. Nepotřebujete GPU cluster ani
tým ML inženýrů.
