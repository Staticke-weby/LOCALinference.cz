Vývojáři mají nejlepší podmínky pro lokální AI: jasná zpětná vazba
(testy), dostupná data (repo) a kultura code review. Zároveň je to
oblast, kde agent může snadno změnit víc, než měl. Proto sandbox
a testy nejsou volitelné.

## Rychlá odpověď

- **Coding agent** je užitečný na testy, refaktoring a vysvětlení kódu.
- **Qwen3.8 Flash Next** má silné coding benchmarky, ale nezná váš
  projekt.
- **Testy a review** jsou povinné; agent nenahrazuje odpovědnost.
- **Sandbox** chrání repo, klíče a produkci.

## Kde to dává smysl

| Úloha | Co model dělá | Riziko |
|---|---|---|
| **Vysvětlení kódu** | popíše, co funkce dělá | neúplný kontext |
| **Testy** | navrhne unit testy | špatné pokrytí |
| **Refaktoring** | navrhne menší změnu | rozbití chování |
| **Code review** | upozorní na problém | falešný poplach |
| **Dokumentace** | návrh README | nepřesnost |
| **Migrace** | návrh kroků | nevratná změna |

## Workflow

1. **Větev** — agent pracuje mimo main.
2. **Kontext** — vyberte relevantní soubory.
3. **Plán** — schvalte kroky.
4. **Změna** — malý diff.
5. **Testy** — v sandboxu.
6. **Review** — člověk přečte diff.
7. **Merge** — až po schválení.

## Co dát agentovi

- **čtení souborů** — orientace,
- **git** — historie a diff,
- **test runner** — ověření,
- **shell** — build a lint, ale v sandboxu,
- **issue tracker** — kontext.

Nedávejte mu produkční klíče, databázi ani main větev.

## Bezpečnost

- **Sandbox** bez sítě, pokud možno.
- **Read-only** repo, dokud agent nepotřebuje zápis.
- **Žádné secrets** v prostředí.
- **Limit** CPU, paměti a času.
- **Kill switch**.
- **Logy** každého příkazu.

## Příklad: oprava testu

Agent dostane selhávající test, přečte funkci a navrhne opravu.
Spustí testy v sandboxu. Člověk přečte diff a schválí merge. Agent
nemá přístup k produkčním klíčům ani k main větvi. To je běžný a
bezpečný workflow.

## Co měřit

- **Počet přijatých změn** vs. odmítnutých.
- **Čas** od zadání po merge.
- **Chybovost** — kolik změn vrátilo testy.
- **Velikost diffu**.
- **Počet incidentů**.

## Kdy to nepoužívat

- **Produkční migrace** bez zálohy.
- **Platební systém** bez schválení.
- **Repo s tajemstvími** bez sandboxu.
- **Kód, kterému nerozumíte.**
- **Automatický merge** bez review.
