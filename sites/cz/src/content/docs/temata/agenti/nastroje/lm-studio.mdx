**LM Studio** je desktopová aplikace pro stahování, spouštění a
testování lokálních modelů. Není to agentní harness; je to
**model runner a chat**, který umí vystavit OpenAI kompatibilní
server, na který se připojí agent.

## Rychlá odpověď

- **GUI pro modely** — GGUF i MLX, stahování a ladění.
- **Server na `http://localhost:1234/v1`** s OpenAI API.
- **Tool use a MCP** — model musí umět tool calling.
- **Není harness** — sám nevede smyčku ani neschvaluje akce.
- **Výchozí bez autentizace** — jen localhost.

## Co to je

LM Studio je aplikace pro macOS, Windows a Linux. Umožňuje:

- procházet a stahovat modely,
- spustit chat s lokálním modelem,
- nastavit kontext a parametry,
- spustit REST server pro aplikace a agenty,
- sledovat využití paměti a rychlost.

Pro agenta je důležitá poslední část: server, který mluví
OpenAI protokolem.

## Připojení k agentovi

1. V LM Studio otevřete **Developer** a zapněte server.
2. Ověřte `http://localhost:1234/v1/models`.
3. V agentovi (pi, omp, OpenCode, Hermes) zadejte base URL
   `http://localhost:1234/v1` a model ID.
4. Otestujte tool calling na jednom nástroji.

```bash
lms server start
```

Server startuje i z CLI. Výchozí port je 1234.

## Endpointy

| Endpoint | K čemu |
|---|---|
| `/v1/chat/completions` | chat a tool calling |
| `/v1/responses` | stavové odpovědi a MCP |
| `/v1/embeddings` | embeddingy pro RAG |
| `/v1/models` | seznam modelů |
| `/api/v1/*` | nativní správa modelů |

LM Studio nabízí i Anthropic kompatibilní endpoint, takže se dá
připojit i klient, který čeká Claude formát.

## Tool use a MCP

- **Native tool use** — model má v aplikaci ikonu kladívka a jeho
  chat template umí tools.
- **Default tool use** — LM Studio se snaží formát převést, ale
  kvalita je nižší.
- **MCP** — od verze 0.4.0, vzdálené MCP jen s výslovným
  povolením.

Když model tool calling neumí, agent dostane text místo volání.
To je nejčastější důvod, proč „agent v LM Studio nefunguje“.

## Bezpečnost

- **Bez autentizace** ve výchozím stavu; server poslouchá jen
  localhost.
- **Síťové vystavení** jen s tokenem a firewallem.
- **Nástroje** mohou sahat na soubory; omezit MCP a tools.
- **Logy** mohou obsahovat citlivé prompty.

## Limity

- **Není harness.** Nemá smyčku, schvalování ani práci s repo.
- **Jeden stroj.** Není to server pro tým.
- **GUI zátěž.** Aplikace běží pořád, i když jen servíruje.
- **Model musí umět tools.** Jinak agent jen chatuje.

## Kdy to nepoužít

- Když chcete agenta, který sám edituje repo.
- Když potřebujete týmový server a oprávnění.
- Když model neumí tool calling.
- Když chcete jen příkazovou řádku.
