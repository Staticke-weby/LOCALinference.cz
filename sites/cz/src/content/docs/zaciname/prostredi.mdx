Než stáhnete model, potřebujete na stroji pár věcí. Není to mnoho —
a většina z nich už tam je.

## Co potřebujete

- **Node 22+** — jen pro build tohoto webu, ne pro běh modelu.
- **Python 3.12+** — pro nástroje kolem modelů: konvertory, skripty,
  `huggingface-cli`, vLLM.
- **Git** — verze konfigurací a měřicích skriptů.
- **Runtime podle zařízení:**

| Zařízení | Runtime |
|---|---|
| DGX Spark | vLLM (oficiální recept), llama.cpp |
| RTX Spark | llama.cpp CUDA, komunitní vLLM port |
| Strix Halo | llama.cpp Vulkan (Windows), ROCm (Linux) |
| Mac | llama.cpp Metal, MLX |

## Jak začít bezpečně

1. Nainstalujte Python a vytvořte virtuální prostředí:

```bash
python -m venv .venv
source .venv/bin/activate
```

2. Nainstalujte `huggingface_hub` pro stahování modelů.
3. Ověřte, že nástroj vidí vaše zařízení (`nvidia-smi`, `rocm-smi`,
   nebo `system_profiler`).
4. Stáhněte menší model na test, než půjdete na Qwen3.8 Flash Next.

## Co nepotřebujete

- **Docker** — užitečný, ale není podmínka. vLLM ho používá, llama.cpp ne.
- **CUDA toolkit** — ovladač většinou stačí; toolkit jen pro buildy.
- **Různé „one-click“ instalátory** z neznámých zdrojů. Modely a skripty
  stahujte z oficiálních míst a ověřujte hash.
