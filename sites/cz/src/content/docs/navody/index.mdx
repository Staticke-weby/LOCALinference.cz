Výrobci obvykle řeknou, jak stroj zapnout, ale ne jak na něm rozjet
model. Tady jsou návody pro každou platformu v katalogu. Cíl je stejný:
**co nejdřív chatovat s modelem** a vědět, co dělat, když to nefunguje.

| Zařízení | OS | Model | Backend |
|---|---|---|---|
| [DGX Spark](/navody/dgx-spark/) | DGX OS (Ubuntu) | Qwen3.8 Flash Next | vLLM, oficiální recept NVIDIA |
| [RTX Spark mini/notebook](/navody/rtx-spark/) | Windows 11 Arm64 | Qwen3.8 Flash Next | vLLM, komunitní ARM64 build |
| [Strix Halo](/navody/strix-halo/) | Windows 11 / Ubuntu | Qwen3.8 Flash Next | llama.cpp Vulkan/ROCm |

## Co mají návody pro lokální AI společné

- **Všechny návody končí u Qwen3.8 Flash Next.** Jiný model v katalogu
  není; web řeší jen tento model a jak ho na daném stroji provozovat.
- **Plný model je velký.** Qwen3.8 Flash Next má přes 100 GB a první
  načtení trvá dlouho. Není to známka poruchy.
- **API je OpenAI-kompatibilní.** Většina klientů (Open WebUI, OpenCode,
  LM Studio, curl) se připojí na `/v1`.
- **Nevystavujte API do internetu.** Lokální server nemá autentizaci.

## Co se u DGX, RTX a Strix Halo liší

- **DGX Spark** má CUDA a DGX OS; nejjednodušší je oficiální vLLM recept.
- **RTX Spark** je Windows Arm64; model berte od NVIDIA (NVFP4) a
  runtime z komunitního vLLM buildu pro ARM64. llama.cpp CUDA je
  oficiální alternativa, ale pomalejší.
- **Strix Halo** je x86 s ROCm/Vulkan; na Windows je nejjednodušší
  Vulkan, na Linuxu ROCm nebo Lemonade build.
