A **mixture-of-experts (MoE)** model has many parameters but activates
only a few per token. Qwen3.8 Flash Next has 180B parameters in total
and activates **6B per token**.

## Why it matters

- **Memory** still has to hold all weights: about 100 GB at 4-bit.
- **Compute per token** is closer to a 6B model, so decode is faster.
- **Bandwidth** still limits decode: each token reads the active
  experts, not the whole model.

## The trade-off

MoE is efficient at inference but needs more memory than a dense model
of the same active size. That is exactly why 128 GB is the minimum:
enough memory for the weights, with room for KV cache.
