Token generation reads model weights. The theoretical ceiling is:

**tokens/s ≈ memory bandwidth ÷ bytes read per token**

For a 6B-active model at 4-bit, one token reads roughly **3 GB** of
active weights. On a 273 GB/s device the ceiling is about **90 tok/s**;
real measurements land lower because of overhead, KV cache and
inefficiency.

## Device bandwidth

| Device | Bandwidth | Theoretical ceiling (3 GB/token) |
|---|---|---|
| DGX Spark | 273 GB/s | ~91 tok/s |
| Strix Halo | 256 GB/s | ~85 tok/s |
| RTX Spark | 300 GB/s | ~100 tok/s |
| Mac Studio | 614 GB/s | ~205 tok/s |

## How to use it

- If a measurement is **above** the ceiling, look for MTP, a smaller
  quantization or an NPU.
- If it is **far below**, look for CPU fallback, heat or a bad
  quantization.
- The ceiling is not a promise; it is a sanity check.
