Before the first model, check the machine, the drivers and the disk.

## Hardware

- **128 GB unified memory** — the minimum for Qwen3.8 Flash Next.
- **Free disk** — 30 GB for the first model, more for video and 3D.
- **Stable power and cooling** — laptops throttle under long runs.

## Software

- **GPU driver** — NVIDIA, AMD or macOS; install updates before models.
- **Python 3.12+** — for helper scripts and runtimes.
- **Git** — to fetch ComfyUI and model repositories.
- **A terminal** — the guides use commands; no GUI is required.

## Accounts

- **Hugging Face** — for gated models and model cards.
- **No cloud account is required** for local inference.
