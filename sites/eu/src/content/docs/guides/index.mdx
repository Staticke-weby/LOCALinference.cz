These guides cover the first run only: from unboxing to a working
model and an API you can reach from another machine. They are based on
vendor documentation and community reports; we do not claim we tested
every step.

## Pick your platform

| Platform | Guide | OS |
|---|---|---|
| DGX Spark | [DGX Spark](/guides/dgx-spark/) | DGX OS |
| Strix Halo | [Strix Halo](/guides/strix-halo/) | Windows 11 or Linux |
| RTX Spark | [RTX Spark](/guides/rtx-spark/) | Windows 11 on Arm |
| Mac | [Mac](/guides/mac/) | macOS |

## What you need for all of them

- The machine with 128 GB of unified memory.
- A stable internet connection for drivers and model weights.
- A Hugging Face account for gated models.
- Patience: the first model load takes minutes.

## A note on numbers

Every speed on this site is taken from a public source, with a date and
a configuration. We do not run our own benchmarks. Where a number is
missing, the page says so.
