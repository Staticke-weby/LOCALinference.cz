Every device has **128 GB of unified memory or more**. The differences
are bandwidth, software stack, cooling and price.

The one exception above 128 GB is [Gorgon Halo 192 GB](/devices/gorgon-halo/):
it gives Qwen3.8 Flash Next more precision and context, not a way to run
huge models.

<TabulkaZarizeniEn />

## What matters most

1. **Software stack.** CUDA (DGX Spark, RTX Spark) has the widest tool
   support. ROCm (Strix Halo) and Metal (Mac) are capable but some tools
   are missing.
2. **Bandwidth.** It sets the ceiling for token generation. 273–614 GB/s
   is the range here.
3. **Form.** A box stays cool and quiet; a laptop travels but throttles.
4. **Price.** The cheapest 128GB path is Strix Halo; the most integrated
   is DGX Spark.

## What runs on all of them

Qwen3.8 Flash Next fits on every device at 4-bit or NVFP4, with 128K
tokens as the recommended operating context. The
[model page](/models/qwen3-8-flash-next/) explains the trade-offs.
