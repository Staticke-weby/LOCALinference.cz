A desktop box stays on, cools better and handles sustained load. A
laptop travels but throttles.

## Desktop

- **Better cooling** — longer video and agent runs.
- **Quieter under load** — a larger chassis.
- **Easier upgrades** — storage, not memory (soldered).
- **Examples:** DGX Spark, Strix Halo, RTX Spark mini, Mac Studio.

## Laptop

- **Portable** — the model travels with you.
- **Battery** — short runs are fine, sustained work needs mains power.
- **Thermal limits** — performance drops after minutes.
- **Examples:** RTX Spark notebook, MacBook Pro.

## When the laptop wins

For work where you sit at the machine and need the answer right away, a
laptop is often the whole solution: it travels with you, runs on battery
during an outage, and the model runs on `localhost`. No server to set up,
no ports to open, no network to secure — the configuration lives on one
device.

The price is throttling and a smaller cooler. If you need steady output
for a team, buy a box.

## How to choose

If the machine stays on a desk and serves a small team, buy a box. If
you need the model on the road and accept slower long runs, buy a
laptop.
