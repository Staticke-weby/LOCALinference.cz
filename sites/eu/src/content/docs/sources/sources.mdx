Every figure on this site has a source and a date. This page explains
what we track and how often.

## Source types

- **Vendor** — model cards, documentation, official benchmarks.
- **Independent lab** — controlled tests, published methodology.
- **Community** — user reports, forums, repositories.

## What we track

- Model releases and licenses.
- Device prices and availability.
- Independent measurements.
- Runtime releases (vLLM, llama.cpp, ComfyUI).

## How to verify a number

Open the device or model page and follow the source link. If a figure has
no source, it is marked as missing, not guessed.
